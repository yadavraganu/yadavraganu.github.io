Client
Major European Bank
Role
ETL Developer
Team Size
8
Duration
Feb 2015 – Jul 2016
Skills

Designed, built, and maintained a global customer name-screening platform for a major European bank. The system screened the bank’s worldwide customer base against sanctions and watchlists to identify potential involvement in illegal activity. I worked across the complete ETL lifecycle, collecting regional branch data, transforming it, and loading it into Oracle in a structured, screening-ready format.

Key Contributions:

  • Analyzed mapping specifications and data requirement documents and recommended design improvements.
  • Developed parallel ETL and sequence jobs using DataStage stages including CDC, Transformer, Join, Lookup, Oracle Connector, and partitioning strategies.
  • Processed incremental delta loads and tuned jobs for throughput, performance, and resource efficiency.
  • Ran and monitored jobs through DataStage Director and Unix, investigated failures using job logs, and validated data using SQL.
  • Supported unit and integration testing, production deployments, database components, Unix scripts, and Control-M scheduling.

Key Responsibilities:

  • Designed and developed PDI transformations and jobs using Formula, CSV File Input, Text File Input/Output, Modified JavaScript Value, and Sort steps.
  • Implemented complex data integration logic using Lookup, Merge Join, Multiway Merge Join, Cross Join, and Sorted Merge steps to meet reconciliation requirements.
  • Built a reusable email notification utility within Pentaho jobs to send automated alerts and reports.
  • Developed secure SFTP jobs for file transfer using Get and Put operations.
  • Applied metadata injection to build dynamic, reusable transformations that receive metadata at runtime.
  • Handled data quality requirements through null handling, row rejection, and error-record routing.
  • Designed Control-M job definitions and tables to schedule and automate ETL batch runs.
  • Supported UAT, resolved defects, and deployed releases across UAT and Production environments.
  • Used GitHub for version control and Jira for sprint tracking and issue management.
